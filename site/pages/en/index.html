API clients on your own disk

Mandor Request sends HTTP and GraphQL. Mandor Realtime keeps WebSocket and Socket.IO connections open. Both save every collection as plain files you can read, diff and commit, with no account and no cloud of ours.

Environments

{{baseUrl}} resolves against the active environment: switch from Local to Staging and the same request goes there. A variable you have not defined stays as literal text and never blocks a send.

POST /oauth/token 200 118 ms 612 B OK

OAuth 2.0

Authorization code with PKCE through a loopback redirect, or client credentials. Set it on a request, a folder or the whole collection; everything below inherits it.

GET /v1/customers/c_2041 304 9 ms 0 B Not modified

Cookies

Cookies a server sets are kept and sent back to it on the next request, the way a browser would. The Cookies tab of the response shows each one it received.

POST /v1/orders 201 16 ms 366 B Created

History

Every send is kept with its request and its response, in the private folder of the workspace that never syncs, for as many sends and days as you choose.

Schema validation

Give a body a JSON Schema, or generate one from a response, and Request marks the place that breaks it while you type.

Mandor Realtime

For everything that keeps talking. WebSocket and Socket.IO from v2 to v4, every frame in one live log, each acknowledgement paired with the message it answers.

  • Reconnects with backoff when the server drops the connection.
  • Records a session, to read it again after the connection closes.
  • Gives each message its own schema.
  • Reads and writes AsyncAPI documents.
  • Runs scripts before connecting, on connect and on each message, once you approve them.

Your work is plain files

YAML and Markdown in a folder you own. Sync it through a git repository you already have, or delete the app and keep every file.

  • Local first. Nothing needs a server of ours.
  • No account. Not now, not later.
  • No telemetry. The apps only ask GitHub whether a new version is out.
  • Secrets apart. They go to your system’s secure storage, never to your files.
