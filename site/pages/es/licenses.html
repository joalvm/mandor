El código de cada versión

Cada release de cada app se construye desde un tag del repositorio, y su página enlaza ese tag y el archivo de su código que genera GitHub. Un tag nunca se mueve ni se borra, así que el código de cualquier versión que descargaste sigue donde dice su release.

Las descargas enlazan el tag de cada versión junto a sus instaladores.

Contribuir

Una contribución entra bajo el acuerdo de licencia de contribución, firmado una vez en el primer pull request. Conservas el copyright de lo que contribuyes; el acuerdo deja al proyecto distribuirlo, también bajo otra licencia más adelante, sin preguntar a cada contribuidor anterior.

Avisos de terceros

Las apps se construyen sobre otro software libre. Cada instalador lleva THIRD-PARTY-NOTICES.txt, con el nombre, la versión, la licencia y el texto de licencia de cada paquete que contiene, junto a la licencia de Mandor, los avisos de los iconos y la política de marcas.

Cada release adjunta además el mismo archivo por separado, con el nombre de la release, como Mandor-Request-{{latest.request}}-THIRD-PARTY-NOTICES.txt, y lo lista en SHA256SUMS.

Electron y Chromium

Las apps corren sobre Electron, bajo la licencia MIT, que corre sobre Chromium, hecho de cientos de componentes con sus propias licencias. Cada instalador conserva ambos avisos tal como los trae Electron:

Sistema Dónde están
Windows y Linux Junto al ejecutable de la app
macOS Dentro de la app, en Contents/Resources

LICENSE.electron.txt tiene la licencia de Electron, y LICENSES.chromium.html la de cada componente de Chromium.

Entre ellos está FFmpeg, bajo la GNU Lesser General Public License v2.1, como una biblioteca aparte (ffmpeg.dll, libffmpeg.so o libffmpeg.dylib) que las apps toman sin cambios de Electron y que se puede reemplazar. Su código se publica con el de Electron, en la versión que usa cada app.
