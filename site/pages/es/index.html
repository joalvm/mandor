Mandor Request

Para todo lo que responde una vez. Cada envío queda en el historial de abajo; abre una fila para ver qué hace Request con él.

GET /v1/health 200 4 ms 17 B OK
GET /v1/orders?status=open 200 42 ms 3,1 KB OK

Entornos

{{baseUrl}} se resuelve con el entorno activo: cambia de Local a Staging y el mismo request va allí. Una variable que no definiste queda como texto literal y nunca bloquea un envío.

POST /oauth/token 200 118 ms 612 B OK

OAuth 2.0

Authorization code con PKCE por un redirect de loopback, o client credentials. Lo configuras en un request, en una carpeta o en toda la colección, y todo lo que está debajo lo hereda.

GET /v1/customers/c_2041 304 9 ms 0 B Sin cambios

Cookies

Las cookies que pone un servidor se guardan y vuelven a él en el siguiente request, como haría un navegador. La pestaña Cookies de la respuesta muestra cada una que llegó.

POST /v1/orders 201 16 ms 366 B Created

Historial

Cada envío se guarda con su request y su respuesta, en la carpeta privada del workspace que nunca se sincroniza, por tantos envíos y días como elijas.

PUT /v1/orders/o_8812/status 422 23 ms 214 B Inválido

Validación de esquema

Dale a un body un JSON Schema, o genera uno desde una respuesta, y Request marca el lugar que lo rompe mientras escribes.

POST /graphql 200 64 ms 1,8 KB OK

GraphQL

Queries y mutations con sus variables, completadas con el esquema que Request lee del servidor.

GET /v1/orders/o_8812 200 31 ms 402 B OK

Snippets de código

Copia cualquier request como curl, PowerShell, fetch, axios, PHP, Python requests, Go, Java OkHttp o C# HttpClient.

DELETE /v1/sessions/current 204 15 ms 0 B Sin contenido

Scripts

JavaScript antes y después de un envío, para firmar, encadenar o comprobar, en un sandbox. Un script que llegó de otra persona espera a que lo apruebes aquí.

GET /v1/products?page=2 503 2,4 s 0 B No disponible

Importaciones

Trae una colección desde OpenAPI, Postman o HAR, un workspace entero desde Postman, Insomnia o Bruno, o pega un comando curl en una pestaña nueva.

PATCH /v1/customers/c_2041 200 27 ms 288 B OK

Mandor Realtime

Para todo lo que sigue hablando. WebSocket y Socket.IO de la v2 a la v4, cada marco en un log en vivo, cada acknowledgement junto al mensaje que responde.

  • Se reconecta con backoff cuando el servidor corta la conexión.
  • Graba una sesión, para releerla después de que la conexión se cierre.
  • Le da a cada mensaje su propio esquema.
  • Lee y escribe documentos AsyncAPI.
  • Corre scripts antes de conectar, al conectar y en cada mensaje, cuando los apruebas.

Tu trabajo son archivos de texto

YAML y Markdown en una carpeta tuya. Sincronízala con un repositorio git que ya tienes, o borra la app y conserva cada archivo.

  • Local primero. Nada necesita un servidor nuestro.
  • Sin cuenta. Ni ahora ni después.
  • Sin telemetría. Las apps solo preguntan a GitHub si hay una versión nueva.
  • Secretos aparte. Van al almacén seguro de tu sistema, nunca a tus archivos.
