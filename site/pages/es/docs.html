Docs

Guías cortas para poner en marcha cada app, y cómo comprobar un instalador antes de abrirlo. Lo demás vive en el repositorio, junto al código que describe.

Guías

  • Empieza con Request Un workspace, tu primer request, entornos, los archivos que escribe, git y scripts.
  • Empieza con Realtime Un workspace, tu primera conexión, entornos, los archivos que escribe, git y scripts.
  • Verificar e instalar Comprueba el checksum y dónde se construyó el instalador, y ábrelo en Windows, macOS o Linux.

Referencia

  • Scripts: cada objeto y función que un script puede usar, en ambas apps.
  • Seguridad: cómo reportar una vulnerabilidad y qué importa más.
  • Versiones: las notas de cada versión de cada app.
  • Issues: un bug, una pregunta o una idea.
